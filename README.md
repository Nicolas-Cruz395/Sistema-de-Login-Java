# Sistema-de-Login-Java
🔐 Sistema de Login em Java

Sobre o projeto:

Este é um sistema simples de login desenvolvido em Java, com o objetivo de treinar lógica de programação.

O sistema permite:

Cadastro de usuário e senha
Validação de idade (apenas maiores de 18 anos)
Sistema de tentativas limitadas (3 tentativas)
Mensagens específicas para cada tipo de erro
Tecnologias utilizadas:

Java
Scanner (entrada de dados)
Como executar:

Compile o arquivo:
javac Login.java

Execute:
java Login

Aprendizado:

Uso de condicionais (if/else)
Estruturas de repetição (while)
Manipulação de entrada com Scanner
Comparação de Strings com equals()
Autor
